# 05 營運規則與常見問題填寫表

這份文件用來收集網站 FAQ、入住須知與訂房前提醒。  
請用旅客看得懂的方式填寫。不確定的欄位可以先填「待確認」。

## 階段狀態

```text
階段性收束：基本規則已整理，部分營運細節待後台補充確認。

已確認的基本營運規則可以保留。
待確認項目必須繼續保持 draft 或待確認狀態。
未確認的費用、押金、時間、人數限制及取消規則，不得標記為 published。
未確認內容不得顯示於公開正式網站。
未來完成 CMS 後台後，業主可以自行補充、修改及發布這些內容。
```

## 入住與退房

### 入住時間
請填寫：

```text
入住時間為下午 4 點後。若房間提前整理完成，我們會主動通知，並盡量協助旅客提早入住。
```

### 退房時間
請填寫：

```text
退房時間為上午 11 點前。
```

### 提前入住
請填寫是否可提前入住，以及需要符合什麼條件。

```text
若房間提前整理完成，我們會盡量協助提早入住；實際可入住時間仍以當日房務整理進度為準。
請不要寫成保證一定可以提早入住。
```

### 延後退房
請填寫是否可延後退房、是否收費、如何確認。

```text
待確認。
如有延後退房需求，請提前詢問；是否能安排需依當日房況及房務作業確認，相關費用待確認。
在費用及最晚退房時間確認以前，不可對外承諾。
```

## 訂金與付款

### 訂金
請填寫訂金金額或比例、付款期限。

```text
待確認。
請不要自行設定訂金比例、付款期限或逾期取消規則。待實際使用的訂金制度確認後，再補入文件。
```

### 尾款
請填寫尾款付款時間與方式。

```text
待確認。
請不要自行設定為入住前、入住當天或退房前。待確認目前實際營運流程後再補入。
```

### 付款方式
請填寫可接受的付款方式，例如匯款、現金、刷卡、行動支付等。

```text
待確認。

- 銀行轉帳
- 現金
- 信用卡
- LINE Pay
- 其他電子支付

未確認的付款方式不可顯示於公開網站。
```

### 取消規則
請填寫取消、延期、退訂規則。

```text
待確認。
請不要自行套用一般旅宿業常見比例，也不要自行設定取消天數、扣款比例或退款期限。

請分開記錄：
- 取消規則：待確認
- 改期規則：待確認
- 保留訂金規則：待確認

未確認前，不要將取消、改期與保留訂金視為相同規則。
```

### 天候或颱風規則
請填寫遇到颱風、停航、停飛或不可抗力時的處理方式。

```text
待確認。

待確認項目：
- 是否依澎湖縣政府或相關單位公告處理。
- 航班或船班取消時是否可延期。
- 是否可退款。
- 訂金可保留多久。
- 改期是否有次數或期限限制。
- 旅客自行取消但交通仍正常時如何處理。

正式規則確認前，網站只可顯示：
「如遇颱風、停航或停飛等不可抗力因素，請與民宿聯絡，將依實際交通及公告情況協助處理。」
```

## 交通與服務

### 接送服務
請填寫是否提供接送、地點、人數限制、預約方式。

```text
樂圖漫遊會館提供機場及港口接送服務，如有需要，請於入住前提前告知抵達時間、班機或船班資訊及同行人數，以便安排。

接送需提前預約，並由民宿確認後才算完成預約，不可寫成隨時保證提供。

接送人數與時間限制：待確認。
請保留以下待確認欄位：
- 單次可接送人數。
- 可提供接送的時段。
- 超過人數時是否分車或另行安排。
- 延誤或臨時更改時間的處理方式。
- 接送是否免費及適用條件。

正式限制確認前，網站只顯示「需提前預約並由民宿確認」。
```

## 入住規則

### 加床
請填寫是否可加床、費用、人數限制。

```text
部分房型可加床，如有需求請於訂房前或入住前提前告知。實際可加床數量、適用房型與費用，需由民宿依房型及入住人數確認。

實際加床數量與費用待確認。
請不要讓網站自行推算，也不要寫成所有房型都保證可以加床。
```

### 兒童
請填寫兒童入住、嬰兒床、備品、收費方式。

```text
待確認。
請分開保留以下欄位：
- 兒童年齡定義。
- 是否與成人同價。
- 是否可免費不佔床。
- 是否提供嬰兒床。
- 是否提供嬰兒澡盆或兒童備品。
- 早餐或其他服務是否另計。

在規則確認以前，不要對外顯示免費、不加價或提供嬰兒用品。
```

### 寵物
請填寫是否可攜帶寵物、限制與清潔費。

```text
待確認。
在正式確認前，不要公開顯示「可攜帶寵物」或「禁止寵物」，避免與實際接待方式不一致。
```

### 吸菸
請填寫是否禁菸、可吸菸區域與違規處理。

```text
全館室內禁止吸菸。如有吸菸需求，請先向民宿人員詢問適合位置，並避免影響其他旅客及附近住戶。
```

### 烤肉
請填寫是否可烤肉、使用時間、清潔規則、是否需預約。

```text
Tour 館包棟旅客如有烤肉需求，請於入住前提前告知；如需協助代訂食材，也請事先預約。實際使用方式、可使用時段及清潔規定，依民宿確認為準。

已確認：
- Tour 館包棟可提供烤肉場地。
- 如需代訂烤肉食材，必須提前預訂。

待確認：
- 烤肉可使用時間。
- 是否限包棟旅客使用。
- 是否提供烤爐、烤網、木炭及餐具。
- 是否收取場地費或清潔費。
- 使用後垃圾與設備整理方式。
- 天候不佳時的處理方式。
```

### KTV

```text
Tour 館設有 KTV 設備，使用時間及相關規範依現場說明為準。為避免影響附近住戶，晚上 10 點後請停止使用高音量設備。

已確認：
- KTV 可供 Tour 館包棟旅客使用。

待確認：
- 「下午 3 點至晚上 10 點」是否為正式使用時間。
- 是否不另外收費。
- 詳細音量規範。
- 其他現場使用規定。
```

```text
Tour 館備有麻將桌，如有使用需求請提前告知；押金、使用時間及相關規定依民宿確認為準。
```
