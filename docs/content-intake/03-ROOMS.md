# 03 房型資料填寫表

這份文件用來收集每一間房型的正式資料。  
不確定的欄位可以先填「待確認」。

## 階段狀態

```text
狀態：階段性確認通過。
基本資料已確認，待補正式網址、照片、詳細介紹及最多入住人數。
尚未完成的資料不可標記為 published。
目前不得匯入公開正式網站。
```

## 已確認的房型規則

```text
Love 館：房號 1 開頭，共可入住 19 位。
Tour 館：房號 2 開頭，共可入住 18 位。
雙人房：一大床。
三人房：一大一小床。
四人房：兩大床。
```

## Slug 命名規則

```text
目前 slug 先標記「待產生」。
未來在房型正式名稱、所屬館別及房號都確認後，再依統一規則自動整理。

建議格式：館別-房號-房型英文名稱
範例：love-201-double-room、tour-301-family-room

原則：
- 全部使用小寫英文字母、數字及連字號。
- 不使用中文、空格或底線。
- 每個 slug 不可重複。
- 不自行翻譯尚未確認的正式房名。
```

## 目前仍需逐房確認的資料

```text
每間房已確認：所屬館別、房號、正式房名、建議入住人數、床型及床數、是否可加床、顯示順序、房內設備、衛浴設備。

仍需逐房補齊：
- 最多入住人數，目前維持「待確認（可加床，實際加床人數與費用另行確認）」。
- 詳細介紹，目前維持「待確認」，未來依房型名稱、照片、實際特色與設備分別撰寫。
- 奧丁丁訂房網址。
- 封面照片檔名。
- 相簿照片檔名。

未取得正式資料前，不可自行推算最多入住人數，不可使用示範訂房網址，也不可把所有房型導向同一個未確認頁面。
```

## 照片命名規則

```text
目前封面照片與相簿照片全部先填「待確認」。
未來收到正式照片後，再依統一規則重新命名。

範例：
- love-201-cover.webp
- love-201-01.webp
- love-201-02.webp
```
