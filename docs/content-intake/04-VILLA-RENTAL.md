# 04 包棟資料填寫表

這份文件用來收集包棟頁會使用的正式資料。  
不確定的欄位可以先填「待確認」。

## 階段狀態

```text
狀態：階段性確認通過。
包棟基本資料已確認。
押金、訪客、額外清潔費、垃圾處理及設備詳細規範仍待確認。
KTV、麻將及烤肉的使用方式與時間仍待確認。
LINE 官方帳號網址與奧丁丁包棟網址仍待確認。
尚未完成的資料不可標記為 published。
目前不得匯入公開正式網站。
```

## 基本資料

### 包棟館別

請填寫：

```text
Tour 館整棟。
```

### 適合人數

請填寫建議入住人數：

```text
14～18 人，適合家庭、朋友及團體旅遊。
```

### 最多人數

請填寫可接受的最多入住人數：

```text
18 人（不加床）；加床後最多入住人數、加床數量及費用待確認。
請不要自行推算加床後的最多人數，也不要公開尚未確認的上限。
```

### 房間配置

請填寫包棟包含哪些房間、每間可住幾人。

請填寫：

```text
Tour 館共 6 間房：
- 2201：愛情海豪華雙人房
- 2202：旅圖四人房 A
- 2203：隱夏雙人房
- 2301：VIP 沐星星空四人房
- 2302：旅圖四人房 B
- 2303：湛藍雙人房
```

### 床型配置

請填寫每間房的床型與床數。

請填寫：

```text
依 Tour 館現有房型配置：
- 3 間雙人房，每間配置 1 張雙人床
- 3 間四人房，每間配置 2 張雙人床
- 全館合計 9 張雙人床
- 不加床的標準入住容量為 18 人
```

## 空間與設備

### 公共空間

請填寫客廳、餐桌、交誼空間、戶外空間等。

請填寫：

```text
有客廳、餐桌、交誼空間、戶外空間。
```

### KTV

請填寫是否提供、使用時間、音量限制、是否需另外收費。

請填寫：

```text
有提供 KTV 使用，使用時間為下午 3 點到晚上 10 點，不需額外收費。
```

### 麻將

請填寫是否提供、設備內容、使用規則。

請填寫：

```text
有提供麻將桌，需押金 $1500。
```

### 烤肉

請填寫是否提供場地、器材、食材、清潔方式、是否需提前預約。

請填寫：

```text
提供烤肉場地，食材需提前預訂。
```

### 廚房或餐飲設備

請填寫是否有廚房、冰箱、飲水機、微波爐、餐具等。

請填寫：

```text
廚房設施包含冰箱、開飲機、微波爐、電陶爐、餐具等。
```

### 電梯

請填寫是否有電梯，或是否需走樓梯。

請填寫：

```text
有電梯。
```

### 停車

請填寫可停幾台車、停車位置、是否需預約。

請填寫：

```text
不需特別說明。
```

### 接送

請填寫是否提供機場或港口接送、是否需預約、可接送人數。

請填寫：

```text
有提供機場與港口接送，需提前預約。
```

## 使用規則

### 使用時間

請填寫入住、退房、公共空間、KTV、烤肉等使用時間。

請填寫：

```text
Love 館與 Tour 館進房時間都是下午 4 點，退房時間是上午 11 點；如果房間提早整理好，可以提早辦理入住。
```

### 噪音規範

請填寫安靜時間、KTV 音量、戶外活動限制等。

請填寫：

```text
晚上 10 點過後，戶外請降低音量。
```

### 入住注意事項

請填寫押金、訪客、垃圾、設備使用、清潔或其他提醒。

請填寫：

```text
已確認：
- 全館室內禁止吸菸。
- 晚上 10 點後，戶外請降低音量，避免影響附近住戶。
- 設備使用完畢後，請依現場說明關閉並妥善使用。
- 如有設備損壞或異常，請立即通知民宿人員協助處理。
- 加床、接送及其他特殊需求，請於入住前提前告知。

待確認：
- 是否收取押金。
- 訪客規定。
- 額外清潔費。
- 垃圾分類及處理方式。
- 設備損壞賠償原則。
- KTV、麻將、烤肉的詳細使用時間與規範。
```

## 訂房與詢問

### 包棟訂房方式

請填寫建議旅客如何詢問或訂房。

請填寫：

```text
包棟訂房請先透過 LINE 官方帳號或電話聯絡，提供預計入住日期、人數及需求，由民宿人員確認房況與相關細節。

目前不提供網站直接完成包棟付款或確認訂單的功能。
```

請填寫希望旅客點擊 LINE 時帶入的文字。

請填寫：

```text
您好，我想詢問樂圖漫遊會館 Tour 館包棟，資料如下：

入住日期：
退房日期：
入住人數：
是否有兒童：
是否需要加床：
是否需要機場或港口接送：
其他需求：

麻煩協助確認房況與相關資訊，謝謝。

此文字保留為未來 LINE 包棟詢問按鈕的預設訊息。
```

### 奧丁丁訂房網址

請填寫完整網址，若尚未確認可填「待確認」。

請填寫：

```text
待確認。
在正式網址及包棟訂房方式確認以前，不可使用示範網址，也不可直接導向一般房型訂房頁。
```
