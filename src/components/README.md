# Components

這裡放 Astro UI 元件的正式實作或 prototype 實作。

預計類型：

- `Button`
- `Header`
- `Footer`
- `SectionHeading`
- `MediaImage`
- `ContactActions`

Phase 4 已建立首頁靜態 prototype 使用的元件。

Phase 3 已先在 `src/design-system/components/` 建立 component contracts。  
正式實作元件時，應先遵守那些介面與 tokens。

目前結構：

- `home/`：首頁區塊。
- `site/`：Header、Footer。
- `ui/`：小型共用 UI，例如 CTA、section heading。
